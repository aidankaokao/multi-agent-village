# 網路研究員：規劃與進度

> 最後更新：2026-10-18（W1 完成，使用者部署實測通過）。每完成一步就更新這份文件。

上網查資料、附引用來源回答的獨立 agent。在村子裡是駐村專家「網路研究員」，補上村民「答不了即時資訊」的缺口；
搭配村子的迴圈（審稿人檢查有沒有附來源，不通過就退回研究員補資料）可以展示多輪協作。

## 已確定的決定

1. **獨立開發、獨立部署**（同台灣史專家、文件彙整師）：`extra-agents/web-researcher/`，127.0.0.1:8102。
2. **搜尋引擎用自架的 SearXNG**：和研究員在同一個 docker-compose，不開 port（只有研究員連得到），不需要任何付費 key。
   映像檔版本釘在 `searxng/searxng:2026.10.17-1c10abe2d`（`.env` 的 `SEARXNG_IMAGE` 可以換）。
3. **流程**：LLM 改寫成 1～3 組搜尋關鍵字（JSON）→ SearXNG 搜尋（各組結果輪流取、去重、同一網站最多 2 頁）
   → 讀網頁（最多 6 頁、4 頁平行）→ trafilatura 取正文 → 程式依字詞重疊挑段落（每頁最多 3 段、共 10 段）
   → LLM 只根據段落回答、標 [編號]（串流）→ 只列出回答裡實際引用的來源。
4. **今天的日期由程式提供**：關鍵字與回答都知道今天幾號（「最新」「今年」要用對年份；時效性內容寫出資料日期）。
5. **LLM 由呼叫端每次帶進來**（同台灣史專家的 header）；沒有 LLM 時關鍵字用原問題、直接列出找到的資料。
6. **安全**：只抓 http(s) 公開位址（每次轉址都檢查，內網 / 本機 / 保留位址一律不抓，避免被拿去探測內網）；
   每頁最多 2MB、10 秒；只收網頁與純文字；網頁內容當資料不當指令（提示詞明講）；容器根目錄唯讀、非 root。
7. **引用格式和台灣史專家相同**（data 的 `citations`：n、title、section＝網站・日期、url）：村子不用改程式就會附上「資料來源」。
8. **回答被截斷時**（本機 Ollama 預設上下文只有 4096 token）：自動只留一半資料重寫；還是截斷就註明並提示調大
   `OLLAMA_CONTEXT_LENGTH`。

## 階段與進度

### W1：專家本體 ✅（等使用者部署實測）
- [x] 搜尋（`app/search.py`）、安全抓網頁與取正文（`app/fetch.py`）、研究流程（`app/research.py`）
- [x] HTTP：`/health`（SearXNG 連得上嗎）、agent card、`/search`（只搜尋）、`/ask`、`/a2a`（send、stream：進度＋逐字回答）
- [x] 指令 `uv run wr search | ask | serve | gen-token`；測試網頁（連線設定與記住設定同文件彙整師）
- [x] Dockerfile、docker-compose（研究員＋SearXNG）、`build.sh`（自動產生存取 token 與 SearXNG 金鑰）
- [x] 單元測試 7 個（不連網路、不連 LLM）；容器實測（本機 SearXNG ＋ Ollama qwen3.5:9b）：電價、高鐵票價都附上來源與日期
- [x] 村子整合實測：研究員查 → 審稿人檢查來源 → 不通過退回研究員（迴圈）。發現村長多排了一步「研究員依意見再查」，
      已在村子加上「審查後的重做步驟由迴圈處理，多餘的移除」
- [x] 使用者部署實測（DeepSeek：科技新聞 16 秒；電價＋審稿人迴圈 47 秒，第 1 輪缺來源編號被退回，第 2 輪通過）
