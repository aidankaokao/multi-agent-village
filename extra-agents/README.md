# extra-agents：獨立開發、獨立部署的外接 agent

比較複雜的 agent（自己的資料、檢索、模型設定）不放進村子的程式裡，而是在這裡各自成為一個完整的服務：

- 每個子資料夾自成一個專案：自己的程式、`docker-compose.yaml`、`.env.example`、說明文件、測試
- 自己 build、自己部署，不依賴村子的程式碼；村子掛掉或改版不影響它，反之亦然
- 開發完成後，村子用 HTTP（A2A 協定）把它接成「外地來的村民」：在村民管理頁填網址即可，不用改村子的程式

和 `agents/` 的差別：`agents/` 只是村子內建村民的設定檔（第一次啟動匯入 DB），`extra-agents/` 是完整的獨立服務。
