📰 報社 · 測試

這個網頁模擬「另一個應用程式呼叫 agent API」：用 A2A 的 message/stream 把採訪資料（base64 的 txt / md）和要求送出， token 與 LLM 設定放在 HTTP header。報社自己不上網找資料：在村子裡由網路研究員查好再交過來；這裡可以直接上傳或貼上資料測試。

⚙️ 連線設定
不勾「記住」時，設定只存在這個分頁的記憶體裡，重新整理就要重填。 勾選時用這個瀏覽器專屬、無法匯出的金鑰加密（WebCrypto AES-GCM，金鑰存在瀏覽器的 IndexedDB）後才存：電腦上的檔案是密文， 但能用這個瀏覽器打開這個網頁的人都能直接使用這些設定（和瀏覽器記住密碼一樣），公用電腦不要勾。
